# HealthLens Frontend

Owners: Teammate 2 (patient UI), Teammate 3 (doctor UI)

React + TypeScript + Tailwind + Recharts, via Vite.

## Setup
npm install
npm run dev   # http://localhost:5173

## Structure
- src/pages/patient/   Teammate 2
- src/pages/doctor/    Teammate 3
- src/mock/            hard-coded data to build against before the real API exists
- src/api/             real API calls go here once backend endpoints are ready
- src/components/      shared UI pieces
